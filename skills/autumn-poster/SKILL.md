# 技能：北京赏秋海报页

## 目标
生成一张**竖版、单文件 HTML** 的赏秋分享海报，保存到 `output/poster-<景点或主题>.html`。

## 执行步骤
1. 确定主角：用户指定的景点；没指定就从 `get_autumn_spots` 里挑一个正当季的（配合 `get_autumn_index`）。
2. 取数：最佳观赏期、门票、交通、一句亮点，全部来自工具返回。
3. 用 `write_file` 写入 `output/poster-<英文短名>.html`。
4. 回复文件路径 + 一句「用浏览器打开后可直接截图发朋友圈」。

## 版式要求
- 竖版 9:16 视觉：容器宽 420px，居中，圆角 20px，投影
- 自上而下：大标题（景点名）→ 一句 slogan → 3 行关键信息（最佳期/门票/交通）→ 一句金句 → 底部话题标签
- 配色：红墙 `#8C1F28` 打底、金叶 `#D8A24A` 点缀、暖白文字
- 全部内联样式，不引用任何外链资源；不要用真实照片（可用 CSS 渐变模拟秋色）

## 禁止
- 不要输出 Markdown 当作结果，必须落盘成 HTML 文件
- 不要编造门票价格、观赏期等数据
